Global search와 selected-document-only search를 병합한 뒤 selected document chunk가 top result와 가까울 때만 우선 배치한다. Ask AI와 workspace chatbot은 answer text에 실제로 등장한 `[n]` citation만 UI source로 반환하고, source display number를 answer 등장 순서의 `1..n`으로 정규화하며, source item은 해당 document link로 이동한다. Workspace chatbot은 이전 assistant answer의 citation marker를 다음 retrieval/prompt history에서 제거하고, 동일 timestamp의 persisted turn은 user-before-assistant display order를 유지한다. Assistant answer body는 공통 Markdown renderer로 bullet/bold marker를 raw text 대신 HTML로 표시한다. Workspace chatbot은 failed turn의 orphan user message를 남기지 않는다. Active chatbot thread는 PostgreSQL partial unique index로 user+workspace당 하나만 허용한다. Chatbot UI는 thread load, streamed message send, reset, citations, selected document id pass-through, conversation-aware retrieval query, settings-panel chat model override, delayed thread/send/reset race guard를 제공한다.
